도구 실행 2026-10-15, 취약점 데이터베이스 스냅샷 2026-10-14(dependency-check 는 2026-06-28 데이터), 도구 10종, 검증 대상 31종, 실행 오류 8건

운영자의 이해관계 운영자는 측정 대상 도구 중 하나인 BomLens(SK텔레콤 공개 프로젝트)의 메인테이너다. 결과가 기울지 않도록 채점 축은 공개 표준에서 고르고, 회차마다 모든 도구의 공개 릴리스를 같은 조건으로 재며, 정답은 도구 출력이 아니라 실제 빌드 결과로 정하고, 점수를 만든 원시 출력을 모두 공개한다.

이번 회차 요약
  • 의존성 컴포넌트는 BomLens 가 8개 생태계 모두에서 1위이거나 공동 1위다. 2위는 생태계마다 다르다: Java 는 cdxgen 0.83, Node.js 는 ORT 0.84, Python 은 cdxgen 과 osv-scanner 0.93. lockfile 없는 PHP 는 BomLens 만, Ruby 는 BomLens 와 ORT 가 찾았다(cdxgen 은 호스트에 composer 와 최신 Ruby 가 없어 해석하지 못했다).
  • 도달성(신설): 호출되지 않는 취약점을 거른 도구는 osv-scanner(소스), BomLens(소스와 바이너리), grype(바이너리 일부)다.
  • AI 모델 파일(신설): pickle 계열 위험 직렬화를 표시한 도구는 BomLens 하나다.
  • 전 도구를 2026-10-15 기준 최신 정식판으로 측정했다(취약점 DB 스냅샷은 2026-10-14). 채점 규칙도 바꿨다: 라이선스는 찾은 컴포넌트만 대조하고, CycloneDX scope: excluded 와 type: file 항목은 컴포넌트로 세지 않는다.
  • 2026-07 대비: cdxgen 의 Python 간접 의존성 해석이 좋아졌다(0.53 → 1.00). 이미지와 Gradle 계열은 채점 규칙이 바뀌어 직접 비교할 수 없다.
