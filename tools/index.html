Tools

개발에 참여하고 있는 오픈소스 관리 도구입니다. SBOM 생성, 오픈소스 위험 분석, 취약점과 라이선스 관리, 고지문 생성을 다룹니다.

각 카드를 누르면 GitHub 저장소로 이동합니다.

BomLens

로컬에서 동작하는 SBOM(소프트웨어 자재 명세서, CycloneDX 형식) 생성 및 오픈소스 위험 분석 도구입니다. 소스 코드, 컨테이너, 바이너리, 펌웨어 또는 기존 SBOM으로부터 SBOM, 오픈소스 고지문, 보안·라이선스 위험 보고서를 만듭니다. CLI 또는 웹 UI로 쓰며 SaaS가 아닙니다.

github.com/sktelecom/bomlens

TRUSCA

직접 호스팅하는 오픈소스 SCA(소프트웨어 구성 분석) 포털입니다. 취약점(CVE), 라이선스 컴플라이언스, SBOM 관리를 하나의 UI에서 다룹니다. Black Duck·Snyk급 기능을 Apache-2.0 라이선스로 제공합니다.

github.com/trustedoss/trusca

onot

SBOM 문서(SPDX, CycloneDX, Excel)로부터 오픈소스 고지문(OSS Notice)을 HTML, 텍스트, Markdown, PDF로 생성합니다. 오프라인에서 동작하는 타입 안전 Python 코어에 CLI, 로컬 API, 설치형 데스크톱 앱을 제공합니다.

github.com/sktelecom/onot
